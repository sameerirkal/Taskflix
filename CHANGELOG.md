TASKFLIX — Changelog

This file records significant changes to the TASKFLIX project.

Versioning Rules

- Major version: Significant architecture changes or incompatible changes.
- Minor version: New features.
- Patch version: Bug fixes and small improvements.

Do not mark features as implemented or tested unless the work has actually been completed and verified.

---

Version 0.1.0 — Project Planning

Requirements documented

- Simple task creation using description, start date, start time, and end date/time.
- Bulk task import from Excel.
- EOD Excel export with description and task completion status.
- Cloud database and secure authentication.
- Background push notification support, subject to browser and device limitations.
- Separate HTML, CSS, and JavaScript files.
- Documentation and version control.

Planned architecture

- Frontend: HTML, CSS, JavaScript.
- Database and authentication: Supabase.
- Hosting: GitHub Pages.
- Push notifications: OneSignal Web Push.
- Backend scheduling: Supabase Edge Functions or another suitable backend.

Documentation

- PROJECT_CONTEXT.md
- FEATURES.md
- DATABASE_SCHEMA.md
- CHANGELOG.md

Implementation status

- Project requirements documented.
- Feature implementation not yet verified.
- Database not yet confirmed as created.
- Notification scheduling not yet confirmed as configured.
- Automated tests not yet performed.
